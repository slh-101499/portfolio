基于多源数据融合与残差图卷积网络的成都市地铁短时客流预测

课程研究报告 · 独立完成 · 52页

深度学习图卷积网络 Transformer时空预测 多源数据融合

🔍 研究问题

如何精准预测城市轨道交通的短时客流？本研究以成都地铁为场景，融合AFC刷卡数据与18项环境因素，构建端到端深度学习预测模型。

📊 数据规模

成都地铁2023年4月26日—5月26日连续31天AFC数据，覆盖37个站点，融合气温、降水、AQI等18项外部特征。经5分钟区间增量转换与24步滑动窗口切分。

⭐ 核心创新：SeSTAR-Net 模型架构
  • 季节基线编码器 — EMA滑动均值 + 昨日/上周同期客流 → 三层全连接输出周期基线，后续分支仅学习非线性残差
  • 空间编码器 — 双分支 ResGCN 分别建模进出站，残差连接缓解过平滑
  • 时间编码器 — Temporal Transformer 多头注意力，克服 LSTM 长程路径衰减
  • 外部编码器 — MLP 压缩环境因子 → 四分支拼接融合预测

高速列车轴承智能故障诊断

"华为杯"第22届中国研究生数学建模竞赛 · 团队（3人） · 91页

🏅 国家级三等奖
机器学习迁移学习 故障诊断XGBoost SVMDANN

🔍 赛题背景

轴承是高速列车的关键部件，长期处于高转速复杂工况下故障率极高。赛题要求利用台架实验数据（源域）训练模型，对实际列车数据（目标域）进行故障诊断，涉及跨工况的迁移学习挑战。

🛠️ 特征工程

从时域（均值、RMS、峭度、峰值因子、脉冲因子）、频域（频谱能量分布、频谱质心、均方频率）、时频域（小波包能量熵、希尔伯特包络谱、STFT时频图）三角度提取12维特征。统一采样率至32kHz，优先选用驱动端(DE)信号。

⭐ 迁移学习策略
  • TCA-XGBoost — 迁移成分分析对齐源域与目标域分布 + XGBoost分类，最大置信度0.800
  • DANN — 域对抗神经网络无监督迁移，MMD值快速平稳下降至0.112
  • 可解释性分析 — 从特征分布轨迹、域差异量化、代表样本跟踪等五维度实现迁移过程可视化

唤醒长白山——吉林人参品牌年轻化与"悦己"消费路径研究

市场调研报告 · 团队项目 · 65页

市场调研结构方程模型 K-Means聚类PSM定价 文本挖掘Logistic回归

🔍 研究背景

吉林人参产量占全国六成以上，但品牌老化、产品形态单一，年轻消费群体渗透率偏低。如何推动人参从"药材柜台"走向"年轻人的购物车"？本研究通过多源数据融合分析框架提供系统性答案。

📊 数据收集

文献调研：系统梳理产业升级、品牌年轻化与消费价值理论文献。问卷调查：分层配额抽样，回收1856份，有效1732份（有效率93.3%），30岁以下占67.3%。文本挖掘：小红书、抖音、微博采集5000+条有效文本，捕捉自然语境中的真实态度。

🔬 七种分析方法联动
  • K-Means聚类 → 4大消费圈层：国潮文化派、颜值社交派、朋克养生党、实用主义派
  • IPA模型 → 便携性与功效感知为跨圈层通用底盘属性
  • 结构方程模型 → 功能·情感·社交三维价值协同驱动，解释购买意愿超⅔方差
  • PSM价格测试 → 核心价格带与新茶饮高度重合，归入"日常轻养生消费品"心理账户
💡 六大核心发现
  • "高认知、低转化" — 近九成知晓，仅半数购买，信任·体验·身份三重门槛
  • 圈层分化显著 — 国潮文化派占比最大，兼具最高付费意愿与最强传播动能
  • 三维价值耦合 — 功能价值是锚点，情感价值是放大器，社交价值是扩散器
  • 价格认知收敛 — 可接受价格带与主流功能饮料高度重合
